MARIA — WEBSITE ARTICLES STARTER

This ZIP is a PREVIEW / STARTER, not a fully configured daily publishing system.

Includes:
- Original home page with an Articles & Research link
- Articles index and one initial evidence-informed article
- Decap CMS starter files at /admin/

IMPORTANT: Do not upload this ZIP to Netlify yet unless you are ready to replace the current deployed site and understand that this is a draft. The current Netlify Drop deployment has no linked GitHub repository.

To enable the editor:
1. Create a GitHub repository with these site files.
2. Connect the Netlify site to that repository with appropriate build/publish settings.
3. Configure GitHub OAuth for Decap CMS.
4. Replace the placeholder repository in admin/config.yml.
5. Add a Markdown-to-HTML build process so newly authored articles appear on the website; this starter does NOT implement automatic rendering.
6. Test the login, preview, publishing and rollback before use.

The original site and certificates remain embedded in index.html.
